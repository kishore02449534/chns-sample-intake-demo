How sample entry works now

  1. 1A lab member adds a row to the Sample Master File in Box and saves it, the same as today.
  2. 2The website reads the file by itself once an hour. Press Check now to read it straight away.
  3. 3Good rows wait in the Sample Inbox, one card per farm. Rows with a problem are listed with the reason.
  4. 4Someone presses Approve. Only then do the samples go live.

Try it: press "Add a good row", then "Save to Box", then "Check now", then open the farm card and press Approve.
